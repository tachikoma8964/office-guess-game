# 辦公室開票猜猜樂

猜林國漳贏吳宗憲幾票、幾％。兩項各 500 分，最接近者拿走，同樣接近則平分。純積分同樂，不涉及金錢或獎品。

## 玩法

1. 大家打開網頁，按「我要猜」填暱稱與猜測，撕下存根拿到代碼，私訊給主辦人。11/28 16:00 後無法再產生。
2. 主辦人在「主辦人專區」貼上代碼。固定用同一台裝置、同一個瀏覽器，收完按「複製備份」。
3. 開票後輸入兩人的票數與得票率（以中選會公告為準），按「算出得分」。

## 注意

- 猜測只存在主辦人的瀏覽器，網頁不收集、不上傳任何資料。
- 代碼只是編碼，不是加密。代碼裡的時間也能被改，僅供辦公室同樂。
- 投票結束前請勿公開大家的猜測或統計結果，以免被認為是散布選舉民調。
